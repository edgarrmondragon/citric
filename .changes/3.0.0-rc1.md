## 3.0.0-rc1 - 2026-11-02

### ✨ Added

- [#1820](https://github.com/edgarrmondragon/citric/issues/1820) Added a question type enum

- [#1831](https://github.com/edgarrmondragon/citric/issues/1831) Added `Client.mail_registered_participants`

- [#1832](https://github.com/edgarrmondragon/citric/issues/1832) Added `Client.remind_participants`

- [#1835](https://github.com/edgarrmondragon/citric/issues/1835) Made `Client`/`Session`'s `requests_session` accept any HTTP client implementing the new `citric.transport.protocol.HTTPTransport` protocol, not just `requests.Session`. Added `Httpx2Transport` and `Urllib3Transport` implementations in `citric.transport`

- [#1837](https://github.com/edgarrmondragon/citric/issues/1837) Support HTTP protocol in REST API client

- [#1870](https://github.com/edgarrmondragon/citric/issues/1870) Allow customizing connection pool options in the urllib3 and httpx2 transports

- [#1892](https://github.com/edgarrmondragon/citric/issues/1892) Added `RESTClient.import_survey` to import a survey with the `survey-import` REST endpoint (LimeSurvey 7.8.0+)

- [#1894](https://github.com/edgarrmondragon/citric/issues/1894) Added `RESTClient.get_survey_responses` to get survey responses with the `survey-responses` REST endpoint (LimeSurvey 7.8.0+)

- [#1910](https://github.com/edgarrmondragon/citric/issues/1910) Added `RESTClient.export_survey_responses`, `get_statistics`, `get_statistics_overview`, `get_statistics_glance`, `get_version_info` and `get_survey_groups` for the `survey-responses-export`, `statistics`, `statistics-overview`, `statistics-glance`, `version-info` and `survey-groups` REST endpoints

### 🔄 Changed

- [#1865](https://github.com/edgarrmondragon/citric/issues/1865) `Client`, `Session` and `RESTClient` now authenticate lazily, the first time a session key or ID is needed, instead of on creation. Creating a client no longer contacts the server, so invalid credentials are reported by the first request

- [#1895](https://github.com/edgarrmondragon/citric/issues/1895) Requests to LimeSurvey now time out after 300 seconds by default. Set a different limit with the new `timeout` parameter of `Client`, `Session` and `RESTClient`, and implement the new `timeout` parameter in custom `HTTPTransport.request()` methods

### ⚠️ Deprecated

- [#1851](https://github.com/edgarrmondragon/citric/issues/1851) Deprecate `requests_session` parameter in `Client` and `Session` classes in favor of `transport`

### 🗑️ Removed

- [#1867](https://github.com/edgarrmondragon/citric/issues/1867) The `Client.session_class` class attribute was removed

### 🐛 Fixed

- [#1821](https://github.com/edgarrmondragon/citric/issues/1821) Update the `properties` parameter type of `Client.set_question_properties` to exclude restricted properties

- [#1834](https://github.com/edgarrmondragon/citric/issues/1834) Reset `Client.server_version` when the client is closed

- [#1863](https://github.com/edgarrmondragon/citric/issues/1863) Anchor regex used to match the "emails left to send" count in `invite_participants`

### 🛠️ Refactored

- [#1816](https://github.com/edgarrmondragon/citric/issues/1816) Use lazy imports on Python 3.15

- [#1833](https://github.com/edgarrmondragon/citric/issues/1833) Use a typed dict as the return type of `Client.mail_registered_participants` and `Client.remind_participants`

- [#1836](https://github.com/edgarrmondragon/citric/issues/1836) Generalize HTTP transport protocol to dispatch any type of HTTP request

- [#1856](https://github.com/edgarrmondragon/citric/issues/1856) Use `Client.session.call` in `Client.invite_participants()` implementation instead of getting the result from a caught exception

- [#1857](https://github.com/edgarrmondragon/citric/issues/1857) Handle explicit RPC errors early

- [#1864](https://github.com/edgarrmondragon/citric/issues/1864) Handle empty content as any other non-JSON response

- [#1851](https://github.com/edgarrmondragon/citric/issues/1851) Renamed private `Session._session` and `RESTClient._session` attributes to `_transport`

- [#1866](https://github.com/edgarrmondragon/citric/issues/1866) Move RPC request dispatch to its own private method

- [#1876](https://github.com/edgarrmondragon/citric/issues/1876) Integration tests now use ephemeral host ports so they can run alongside a manually started Docker Compose stack
